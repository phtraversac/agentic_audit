Build two segmentations, not one

  • Template (what the page is): home, hubs and categories, content pages, money pages, proof (case studies), plus taxonomies (tags, authors) and pagination. Answers "is my structure sending equity to the right template?"
  • Topic (what the page is about). Answers "do my content pages feed the matching money page and each other?"
  • Cross the two: content x a topic should link to that topic's hub, to the money page that answers it and to related proof.

What makes a good page group

  • One template, one intent. Mixing listings and content hides the problem.
  • Exhaustive. No real page left ungrouped. Test it: ungrouped indexable pages should be 0.
  • Big enough (about 20 pages or more) so averages mean something. Small money groups (pricing, demo) can stay small.
  • Its own demand signal (impressions, visits, conversions) so you can compare demand with equity.
  • Actionable. Someone owns it and one hub page can link to the whole group.
  • Rules on URL folders first, then title or schema type when folders lie. Order the rules so specific ones (pagination) win over folders.

    Anchor rules

    • Use the query the target page already ranks for, in natural words. The "Suggested anchor" column takes the first Google query of each page.
    • Vary it. Across 5 links, use 2 or 3 phrasings of the same intent (exact query, longer variant, question form). Never the same exact anchor sitewide.
    • Never "Learn more" or "here" in body text. Name what the target page delivers.
    • One target, one intent. Do not use the same anchor to point at two different pages: it creates cannibalization.
    • Link early, in context. A link in the first paragraphs of a relevant page beats a link in a related-content block.
    • Image links need an alt text, it acts as the anchor.

    In-text anchor types, by target group

    Matches a ranking query = the anchor contains a query the target already gets impressions for (best). Descriptive = meaningful words but not one of its queries. Generic = "Learn more", "Read more", "here". URL = a raw address. Empty = image link without text.
